SHOPFLOW PRESENTATION PROTOTYPE

Run:
1. Extract the ZIP.
2. Open index.html.
3. Create an account and set a business name.
4. Add products in Stock Lite, including pictures.
5. Open Catalogue.
6. Record a sale.
7. Stock decreases automatically.
8. Add customers and queue entries.
9. Dashboard updates automatically.

For presentations:
Click "Load Demo Data" on Dashboard to populate a sample business.

Prototype note:
This version uses browser localStorage. Passwords are not securely stored, so this is NOT a production authentication system. Production should use a backend, database, secure password hashing, email verification and cloud image storage.
